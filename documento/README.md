# Documento do TCC

O arquivo principal é `main.tex`; os capítulos ficam em `secoes/` e a
bibliografia canônica do projeto fica em `../referencias/referencias.bib`.

O texto atual é um rascunho de trabalho. Marcações `PENDENTE` identificam
trechos que dependem de validação do orientador, dados definitivos,
implementação ou resultados experimentais.

Para compilar localmente, a partir desta pasta:

```bash
latexmk -pdf main.tex
```

O PDF compilado e os arquivos auxiliares do LaTeX não são versionados. Uma
versão destinada a revisão ou entrega deve ser publicada separadamente, com
data ou versão identificável.
